# rag-lore-engine

GraphRAG Character Profile Builder, Continuity Flaw Auditor, and Plotline Predictor for OmniScribe Studio.

## Overview
- Knowledge graph indexing with Neo4j tracking characters, sect hierarchies, and cultivation realms.
- Qdrant vector database storage for semantic chapter retrieval.
- Automated chapter audits flagging narrative contradictions, broken abilities, or sudden tone shifts.
