# ingestion-scraper

Multi-Format Novel Parser (EPUB, PDF, DOCX, MD, TXT), Deduplication Engine, and Scalable Web Novel Scrapers.

## Overview
- Ingests local files preserving chapter hierarchies and metadata.
- Integrated site adapters for Twkan, 69shuba, WTR-Lab, OpenNovel, and Project Gutenberg.
- FlareSolverr proxy connectivity for automated Cloudflare protection bypass.
- SHA-256 fingerprinting for semantic deduplication.
